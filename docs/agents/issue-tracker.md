# Issue tracker: Local Markdown

Issues for this project live under `.scratch/<feature>/issues/`, one numbered Markdown file per ticket. Specs and architecture remain in the project documentation.

Each ticket records its blocking ticket numbers, acceptance criteria, and status. `ready-for-agent` indicates a specified ticket; work can start only when all listed blockers are complete. Use `in-progress` while working and `done` only when the acceptance criteria are verified. Append discussion under a Comments heading when needed.

The approved COBOL translation tickets are under `.scratch/cobol-to-python/issues/`. Read the project documentation and glossary before implementing them. Do not infer approval to implement from publication of a ticket.
